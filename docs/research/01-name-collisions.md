# Name collisions: "Sherpa" (checked 2026-09-10)

**Decision (2026-09-10): the project is named Sirdar.** Second check the same day: `sirdar`
free on npm and PyPI; GitHub handle taken by an inactive user; no notable repos.

Research run before the project was created. Web-search based; no WHOIS, no
trademark database read beyond one USPTO record. Treat as orientation, verify
before publishing.

## Verdict

| Surface | Risk | Why |
|---|---|---|
| GitHub org `sherpa` | High (unavailable) | Taken since 2014 by the Chandra X-ray fitting package (github.com/sherpa/sherpa). `sherpa-sh` also taken. |
| GitHub repo `<you>/sherpa` | Medium | Available under a personal account, but ~20 `sherpa` repos exist and `sherpa-onnx` (14.7k stars) dominates search. Two `sherpa` repos are already AI-agent tools. |
| npm `sherpa` | High (unavailable) | Taken (2016 file watcher). `sherpa-ai` taken (June 2026). `sherpa-cli` unpublished May 2024, availability uncertain. `@sherpa/*` scope empty. |
| PyPI `sherpa` / `sherpa-ai` | High (unavailable) | `sherpa` = Chandra. `sherpa-ai` = Aggregate-Intellect LLM agent framework, 0.6.0 on 2026-07-30. |
| Product name "Sherpa" (AI tool) | High | Six or more funded or launched AI products used the bare name in 2025-26, one of them an ops/observability agent. |

Plain "Sherpa" is crowded in exactly this category. A compound name is the practical route.

## Products and companies already called Sherpa

- sherpa.ai (Bilbao): privacy-preserving AI, raised $18M July 2026.
- sherpahq.ai (Munich): "AI operating system for external work", orchestrates people and agents, pre-seed June 2026.
- sherpa-agent.com: "Talk to your AWS cloud", AI agent for cost, security, observability and ops with a human-in-the-loop gate.
- withsherpa.ai (YC Spring 2026): autonomous conversion-rate optimisation agent.
- sherpalabs.ai (YC, 2025): agentic data team for ETL.
- Aggregate-Intellect/sherpa: open-source agent framework, PyPI `sherpa-ai`.
- AIxCyberChallenge/sherpa: LLM fuzzing **harness** generator, MIT. The word "harness" collides with our framing.
- sherpa.sh: PaaS, GitHub org `sherpa-sh`.
- SherpaDesk: established helpdesk/ticketing product. Same category as us.
- sherpas.dev: Atlassian Marketplace vendor.
- k2-fsa/sherpa-onnx: speech toolkit, the dominant "sherpa" on GitHub, npm, PyPI and crates.io.
- Also: MAUI.Sherpa (Redth), jrasell/sherpa (Nomad autoscaler), sherpa-ai/sherpa (hyperparameter optimisation), omdivyatej/sherpa-ai (npm cursor widget).

## Registries

- npm: `sherpa` taken, `sherpa-ai` taken, `sherpa-cli` burnt, `@sherpa/*` empty. `ticketsherpa` and `sherpa-desk` free.
- PyPI: `sherpa`, `sherpa-ai`, `sherpa-onnx` all taken.
- Homebrew: no `sherpa` formula or cask. Free.
- crates.io: `sherpa` taken but yanked (names are never released). `sherpa-onnx` active.

## Trademark

- USPTO: SHERPA Reg. 7452085 (classes 35/36/42 incl. software and AI research) registered July 2024, cancelled 4 July 2025. Other live class 9/42 marks unverified (list pages returned 403).
- EU: litigated SHERPA v. SHERPA dispute (General Court, 2015). Siemens AG holds a long-standing German word mark SHERPA in class 9 for computer programs. Current EU status unverified.
- Ethnic-name concern is documented: Salon 2017 piece on Silicon Valley's use of "Sherpa"; a 2020 Change.org petition by the Society of Himalayan Leaders Abroad asking companies to drop it; an SIT study on "cultural commoditization". The objection targets the "guide/porter = helper" metaphor, which is exactly the metaphor a support tool invokes. Expect it as a README or issue-tracker argument, not a legal one.

| sherpa-l2 | Clean but opaque. | Low |
| Tenzing | tenzing.team (Jira/ADO alignment platform), Tenzing MEMO, PyPI `tenzing` dead package, GitHub user taken, npm free. A living family's name. | Medium |
| Sirdar | sirdar.ai and sirdar.app exist (unrelated). npm/PyPI free. Occupational term (the sirdar assigns work to the expedition team), so it dodges the ethnonym critique. Also a UK yarn brand. | Low to medium |
| Pasang | No software product found. npm/PyPI free. Means "install" in Indonesian, so search is noisy. | Low |

Recommendation from the research: **Sirdar** if the expedition metaphor matters more than the word, **ticketsherpa** if keeping "Sherpa" matters more.
